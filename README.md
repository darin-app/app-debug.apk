# استودیو صدا

اپ اندروید برای ضبط، ویرایش و میکس موسیقی، با رابط شیشه‌ای و گرادینت و فونت وزیرمتن.

## امکانات

- **پروژه‌ها:** ساخت پروژه‌ی جدید، ذخیره‌ی خودکار، باز کردن، تغییر نام، حذف و «نسخه‌ی جدید» (کپی جدا از پروژه برای تغییر دادن بدون خراب شدن اصل)
- ضبط با میکروفون (با حذف نویز و پخش همزمان بقیه ترک‌ها با هدفون) و جبران تأخیر ضبط
- آپلود ویس و بیت، هر کدام به‌صورت ترک جدا
- **لایه‌بندی:** چند ترک و چند کلیپ روی هم، ترک خالی، انتقال کلیپ بین ترک‌ها، جابه‌جایی ترک‌ها، بی‌صدا، «تک» (solo)، بلندی و چپ‌وراست هر ترک
- **جابه‌جایی:** کلیپ را لمس کنید و بکشید؛ لبه‌ها را برای کوتاه کردن بکشید
- **برش:** برش در نشانگر، یا «حذف یک بخش» (شروع و پایان) از یک کلیپ یا از کل آهنگ، با گزینه‌ی بستن فاصله
- **لوپ:** کپی پشت‌سرهم و «پر کردن تا انتهای آهنگ» برای بیت
- شبکه‌ی ضرب (BPM) برای چسبیدن دقیق کلیپ‌ها
- بلندی کلیپ، محو شدن ابتدا و انتها، معکوس، بلند کردن تا حد مجاز، حذف نویز با امکان بازگردانی
- برگشت و جلو (Undo/Redo)
- **خروجی MP3 یا WAV که مستقیم در پوشه‌ی Music/SedaStudio گوشی ذخیره می‌شود**

## گرفتن فایل APK

### راه ۱: GitHub Actions (بدون نصب چیزی)
1. این پوشه را در یک مخزن GitHub بگذارید.
2. به تب Actions بروید، «ساخت APK» را اجرا کنید (Run workflow).
3. بعد از چند دقیقه، فایل `seda-studio-apk` را از Artifacts دانلود کنید و `app-debug.apk` را روی گوشی نصب کنید.

### راه ۲: روی کامپیوتر خودتان
نیاز: Node.js 22، JDK 21 و Android SDK (یا Android Studio).

```bash
npm install
npx cap sync android
cd android
./gradlew assembleDebug      # ویندوز: gradlew.bat assembleDebug
```
خروجی: `android/app/build/outputs/apk/debug/app-debug.apk`

یا با Android Studio: `npx cap open android` و بعد Build ▸ Build APK.

### تست سریع بدون APK
پوشه‌ی `www` را با هر وب‌سرور محلی باز کنید (مثلاً `npx serve www`) و در Chrome تست کنید. ضبط میکروفون فقط روی `localhost` یا HTTPS کار می‌کند.

## نکات استفاده

- برای حذف نویز بهتر است در کلیپ حدود یک ثانیه سکوت (فقط نویز محیط) وجود داشته باشد. برنامه ساکت‌ترین بخش‌ها را به‌عنوان نمونه‌ی نویز برمی‌دارد.
- اگر هنگام ضبط روی بیت، صدا کمی دیرتر ثبت شد، کلیپ ضبط‌شده را کمی به چپ بکشید.
- خروجی در پوشه‌ی Music ← SedaStudio ذخیره می‌شود و بعد از آن دکمه‌ی اشتراک‌گذاری (مثلاً تلگرام) هم دارید.
- پروژه‌ها داخل خود اپ ذخیره می‌شوند. اگر اپ را پاک کنید یا «Clear data» بزنید، پروژه‌ها از بین می‌روند؛ از آهنگ مهم خروجی بگیرید.

## ساختار

- `www/` کد اپ (HTML/CSS/JS)، فونت‌ها و رمزگذار MP3
- `www/dsp.js` الگوریتم حذف نویز، WAV و موج‌نما (با تست در `test/`)
- `android/` پروژه‌ی اندروید (Capacitor)
- `.github/workflows/build-apk.yml` ساخت خودکار APK
